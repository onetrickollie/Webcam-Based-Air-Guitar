# Webcam Based Air Guitar
This is a project by Kai. I will be making a webcame based air guitar game where you can play notes from a real guitar using similar hand gestures as if you were pressing down on the strings of a guitar. 

# Prototype idea:
1. Real video frames
2. Run MediaPipe hands
3. Dedicated interaction zones
4. Extract knuckle joint Y positions
5. Match left-hand shape → chord
6. Detect right-hand velocity OR finger motion → string pluck
7. Trigger sound (note/chord)
8. Visual feedback (optional but cool)
